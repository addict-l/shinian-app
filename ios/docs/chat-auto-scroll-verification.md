# iOS 普通版聊天自动滚动

2026-10-21。用户审核通过，并明确要求“（关怀版）保持原样”。最终提交只在普通版的故事聊天和人生采访启用自动跟随。

## 最终行为与范围

- 首次进入普通版故事聊天和人生采访时显示最新内容。
- 处于底部时，新讲述、助手回复、内容高度变化以及键盘开合继续跟随最新内容。
- 上翻历史时保留阅读位置；回到底部、点击“回到最新”或主动发送后恢复跟随。
- 采用无动画定位，“回到最新”触控高度至少 44pt。
- 关怀版保留本次任务前的滚动容器、输入框布局和操作；未接入新自动跟随组件。关怀输入组件没有本轮修改。

组件为 [JournalChatHistory.swift](../AIMemoirs/Features/NewMemory/Chat/JournalChatHistory.swift)，使用 SwiftUI 的 ScrollGeometry、ScrollPosition 和 ScrollPhase；最低 iOS 18.1。底部位置按实际内容和可视高度计算，避免重复累加安全区 inset。

## 验证

| 测试 | 检查内容 |

最终结果：独立候选构建成功，4 项 UI 测试全部通过，0 失败、0 跳过。结果见 `standard-final-summary.json`、`standard-final-ui.log` 和 `standard-final.xcresult`。

关怀版各视图块与任务前快照逐字比较一致；提交候选中的关怀视图块与 Git 基线一致。原工作区 25 个其他待处理文件的 SHA-256 均保持不变，另外两个共享视图只暂存本轮滚动修改。
