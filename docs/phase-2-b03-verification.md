日期：2026-10-13。当前状态：实现与自动验收完成；第 26 问用户已明确通过人工验收，并授权正式提交及推送 main。正式云端发布尚未执行。

## 可检查的变化

草稿与已保存回忆都能编辑时间，支持确定、大概记得、记不清、暂时不想说和待补充。点击“核对标题与正文中的时间”后，逐处显示原文、建议文字与上下文，所有选项初始未选。只有点击“应用所选”才改编辑框，点击“保留修改”或“保存修改”才写入数据。

对应原时间的完整表达可以选择替换。多个日期、重复出现的时间、相对时间或不明确归属会提示核对；其他年份保持原样。未识别的自然语言需要手动编辑；不会调用模型推断时间，也不会全局替换年份。标题没有对应时间时不强行添加。长正文最多展示 100 处提示，其余明确提醒手动核对。

3 次隔离云端时间预览完整 HTTP 请求为 0.220–0.311 秒（含 SSH 隧道与网络），没有模型调用。

第 25 问确认的规则已经实现：草稿重新生成保留已确认的手改时间，新生成的标题与正文重新进入校对界面。AI 仍根据原聊天生成有原文依据的草稿，手改时间作为单独的用户更正保存；不会把新年份冒充原聊天中的原文证据。地点、照片、原聊天及其他维度保持原有流程。

时间的 `user_edited` 标记会在读取和保存中保留。更改时间会清除该维度的原聊天引用 ID；原聊天、原文引用与会话信息不修改。精确日期仅从用户明确填写的单个完整日期解析，多个日期或未知状态保持空；明确年份用于现有胶片及回忆列表排序，未知或暂不透露的时间不强行分配年份。

## 协议与保护

- 新增两个只读接口：草稿、已保存回忆的 `POST .../time-preview`，分别携带 revision、version 及当前编辑快照。
- 草稿 PATCH 新增可选 time 字段，老客户端的标题/正文编辑协议继续可用。
- 预览使用 UTF-16 位置和原文字校验；应用前核对完整编辑快照，编辑内容改变后旧建议不能套用。
- 草稿及回忆的原有版本检查继续保护多设备更新；冲突、取消、失败和重试保留本机文字与时间。
- 原文 hash 排除新增的编辑标记，升级前的草稿无需重新生成即可继续编辑及确认。空/非空叙述证据的旧 hash 均已覆盖。
- 无数据库迁移，迁移 head 仍为 `f10100000001`。

1. 在原模拟器测试版打开“我的 → 我的全部回忆 → B03界面”，选择编辑回忆。
2. 修改时间，点击核对时间；先返回编辑，检查输入没有丢失。
