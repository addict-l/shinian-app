# 家庭共享账号服务

本期沿用一家共用一个账号。账号为 3–32 位字母、数字或下划线，忽略大小写；新密码为 8–128 位。注册一次性创建账号、独立家庭和当前设备会话，任何失败都不留下半成品家庭。暂不提供手机／邮箱验证、自助找回密码、个人成员账号或加入已有家庭。

登录每次签发独立的 30 天设备会话。退出家庭服务只撤销当前会话，其他设备继续使用，家庭、人物、聊天、照片、回忆和回忆录均保留。退出需要联网；撤销失败时页面说明重试，不显示虚假的退出成功。

## 数据与接口

增量迁移 `h10100000001` 接在 `g10100000001` 后，仅新增 `family_accounts`、`device_sessions`、`auth_rate_limits` 三张表。旧业务表及其主外键不变。一个账号唯一绑定一个家庭，旧家庭只能由受控命令绑定，公开注册不能认领旧数据；预留旧账号名，默认 `family`。

| 接口 | 结果 |
| --- | --- |
| `POST /api/v1/auth/register` | 201，创建家庭并返回当前设备令牌 |
| `POST /api/v1/auth/login` | 200，核对账号密码并签发新会话 |
| `GET /api/v1/auth/me` | 200，返回服务端确认的账号与家庭身份 |
| `POST /api/v1/auth/logout` | 204，仅撤销请求携带的设备会话 |

账号密码使用带随机盐的 scrypt 哈希；数据库只保存令牌摘要。业务路由统一验证 Bearer 会话，并检查家庭、人物、聊天、草稿、回忆、媒体及幂等请求 ID 的归属。列表即使未传家庭 ID 也只查询登录家庭，跨家庭资源与不存在资源均返回 404。登录与注册有限流，API 返回禁止缓存。

iOS 真机将会话保存在设备 Keychain，模拟器使用独立应用偏好保存。启动先核验会话再展示家庭内容。每次登录创建新的业务适配器和页面状态，旧请求不能接管新账号令牌；草稿、照片、回忆录、本地昵称和头像按服务地址、账号及家庭隔离。旧本地缓存仅允许经服务端认证的原家庭账号复制迁移，原文件保留。升级后旧保存的 Basic 账号密码会尝试正式登录，成功后清除旧密码。

## 交付与验收

本块拟用提交：`feat(auth): 接入家庭共享账号注册登录、设备退出及家庭数据隔离`。

沿用既有奶油色登录、注册界面；保留点击空白收起键盘，不增加“完成”按钮。注册变为真实联网操作，补齐重复账号、校验、加载和服务端错误；设置页明确说明退出范围。验收记录见 [verification.md](verification.md)，正式切换与回退见 [rollout.md](rollout.md)。
