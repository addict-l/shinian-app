## 实现

- 登录页：真实启动时空白账号输入；密码显隐、账号帮助、注册入口、加载状态、空值校验和服务器错误提示。编辑输入会清除过时的服务器错误。
- 注册页：家庭账号、至少 8 位且不能全为空白的密码、确认密码；首个错误字段获得焦点。有效表单仍明确提示注册未开放，提供返回登录入口。
- 共用表单布局：可见标签、系统密码自动填充、密码使用 ASCII 键盘（仍允许粘贴）、至少 44pt 的显隐点击区域、减弱动态效果适配、动态字号、键盘尺寸变化后重新定位输入框。
- 暖纸主题复用现有颜色；新增认证强调色，使白色按钮文字及链接保持足够对比度。
- 登录超时改用登录场景提示，不再显示与内容保存相关的超时文案。

## 人工复核方法

在指定模拟器打开登录设计预览，点击“去注册”，检查表单布局。空表单点击注册，确认逐项错误提示；输入任意账号、8 位以上密码及相同的确认密码，确认仅显示未开放提示。通过“返回登录”回到登录页。普通启动继续连接现有家庭服务。
