# 真实后端生成的六段草稿

2026-10-14。实际模型原文，未经手工润色。这是六份回忆草稿，不是已经编辑完成的整章。

## 桥湾村旧屋里的柴火

小时候我们住桥湾村西边的旧屋。我常帮母亲做饭，抱柴进去时抱得太多，柴掉地上，我先放下剩下的，再一根根捡起来放灶口旁。姐姐在院里洗脸。

## 母亲缝的蓝布书袋

小时候，母亲拆了一件旧蓝褂子，用那块布给我缝了一个书袋，让我试背。我试背了。那个书袋是敞口的，没有拉链。

## 河边捉鱼

上小学时，我和邻居阿兴到河边捉鱼。有一次他捉，我拿着竹篮。

后面发生的事，我已经记不清了。

## 和父亲装谷子

小时候一次放学回家，我帮父亲把院里的谷子装袋。我两手扶袋口，他用簸箕倒谷子。我没扶住一边，谷子撒了。我蹲下捡，父亲叫我先扶好袋口，他捡了地上的谷子。

## 搬锅

1965年，我们从桥湾村西边的旧屋搬到同村东边另一间屋子。母亲把小锅交给我，我两手拎着锅耳，走一会儿放下歇一下，再提起来。到了新屋，我把锅放在灶间门边。为什么搬，我记不清。

## 旧屋漏雨

童年时我住在村西的旧屋。有一回屋里漏雨，母亲让我拿搪瓷盆接水。我把盆放偏了，水还是落在地上。母亲指给我看滴水的位置，我把盆挪了过去。姐姐用旧布擦地，我蹲着听盆里滴水的声音。
