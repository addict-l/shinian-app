# M02｜每次只说一小点：实际采访问答

虚构人物：虚构陈福生（爷爷）。2026-10-14，真实隔离后端 / DeepSeek Flash。

人使用预写底稿，根据后端当前子问题选择对应回答；没有修改 AI 实际回复。

底稿未准备对应子问题时，脚本会回答“这一点我已经记不清了。”。这种回答是测试脚本兜底，不能当作真实老人表现。
