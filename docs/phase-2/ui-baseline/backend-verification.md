## 交付行为

正常 Debug 与 Release 使用现有 HTTPS 家庭服务。真实账号登录和恢复、人物查询与增删、AI 对话及历史恢复、照片上传、草稿生成／修改／重新生成／确认保存、回忆查询与维护、胶片、人物资料、回忆录设置同步和 PDF 导出均接入现有适配器。四个功能共享每次登录创建的适配器和状态。

保留当前暖色 SwiftUI 和统一透明图标底部导航。设计示例只在 Debug 显式预览入口启用；Release 忽略设计预览参数。示例登录不覆盖真实凭据，示例删除不清理真实聊天缓存。

新增账号失效后返回登录、真实统计、按真实故事时间分组、不同人物聊天实例隔离、个人本机头像选择、回忆录同步／重试和独立取景入口。封面缩略图与 PDF 使用同一套排版。

## 验证结果

- 最终 Debug 测试构建与 Release 独立构建通过。
- 82 个 Swift 测试在 18 个 suite 中通过；两项真实联调入口默认受环境开关保护，不在普通回归中执行。其余覆盖登录、状态、草稿恢复、版本、照片、请求协议、统计及 PDF 分页和目录。
- 8 项网络边界检查通过：协议、错误状态、空响应、解码失败、超时、连接失败、取消及 HTTPS 约束。
- 独立数据库中单独运行真实 HTTP + 已配置 AI：人物创建、幂等消息与照片关联、下载重载、历史恢复、草稿编辑与重新生成、幂等确认、回忆编辑与版本冲突、封面上传、制作设置云端同步、PDF 正文与分享前校验、回忆和人物删除通过。
- 4 条界面流程通过：正式家庭资料只读浏览；草稿／回忆编辑删除后的共享统计；封面取景与拼贴、纵向滚动、整本预览与系统分享；隔离后端的真实人物添加、系统照片选择、AI 聊天、回忆保存、PDF、回忆编辑与删除。
- 安装并运行最终 Release，确认即使传入设计预览参数仍显示真实家庭首页；之后恢复无参数正常运行。

真实写入验证使用当前云端镜像启动临时 API，并连接新建的独立随机 MySQL 数据库和独立临时照片目录，经 SSH 转发供现有模拟器访问。测试完成后 API 容器、数据库、临时配置与转发均已销毁；现有家庭业务记录未改写，现有后端未重新部署。
