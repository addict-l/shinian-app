# 单问句题库 v2 改造与真实 DS 回归

日期：2026-10-18。候选：`full-interview-v2.0.0`。结论：本次业务改造及一组真实 DS 测试完成；关键点 24/33（72.7273%），未达到 >95%，不构成正式验收。真实云端与 App 仍是此前人工测试版本，本次候选没有发布或提交验收 commit。

## 题库与代码变化

原 62 个题组合计整理为 **83 道入口单问句**：骨架 11、家乡与童年 10、求学与成长 10、工作与劳动 15、家庭生活 9、后来的生活 8、人生回望 20。

- 相似目标合并：CH01 的早年记忆及其中发生的事合为一个可理解事件；CH04 喜欢的活动、爱好或梦想为一个可用目标，不把同一兴趣当作两个必答答案。
- 独立目标拆题：出生时间／出生地点／家乡样貌；成长照料者／生活来源／兄弟姐妹／家庭氛围；感谢／亏欠；吃苦／努力／运气等各自成为独立问句。
- 递进目标留在同题：工作及选择缘由、概括及解释、家教及本人认定影响、困难及实际应对等。入口未回答时不先问补充；已经主动回答的同题补充不再追问。
- 稳定保留旧字段编号及明确的 `question_id` 所有权；运行引擎、字段复核、评估输入、审计均使用归属而非编号前缀，避免拆题串缓存。适用前提按每个新题自己的字段定位。
- 证据、人物关系、阶段、明确未知／拒绝／否定及处理矛盾方式的原有限制继续执行；不按人物定制提示。

## 测试方法与限制

冻结代码、合同、通用提示后，从现有 55 位开发人物中均匀抽取 8 位，不按结果重抽；包含入选人物所有已映射题例。本组为侯鎮清、易芳運、楼燕勤、孫樸生、金晓贵、周少凤、郭柯、劉金標。抽样种子 `750443787408427674`。

本组 **33 题例、33 检查点、28 道新题**，全部执行。不同新题的材料分别重新输入、状态独立。模型为 `deepseek-v4-pro`，冻结配置 `thinking: disabled`、`max_tokens: 16384`，无 `reasoning_effort`；固定提取→复核→最多一次内部协议修复。实际调用 70 次，记录总 token 246132；推理 token 未作为独立 usage 字段报告，因此不把缺省值当作服务端明确报告的 0。每次实际响应都保留配置见证。

原 v7 金标准与旧失败没有修改。新标注在调用前，按新题归属投影原有事实判据；仅相似目标合并、适用前提与追问路由作本次业务迁移，全部投影在[迁移审计](prototypes/full-interview-evaluation/single-question-v2-gold.projection.json)保留。当前 55 人投影资料覆盖全部 83 题，但本次实际模型只运行上述 8 人／28 题。新旧题的检查点数量及路由不同，不能直接把本轮百分比与旧 62 题百分比相减来证明升降。

这是**公开真实访谈的提取及判定回归**：没有改写历史采访者问法或受访者原话，也没有让模型扮演这 8 个人回答新题，不能据此宣称已经验证真实长辈与新问法的完整实时交互体验。标注属于已用于开发的资料，非盲测；争议按冻结预期计失败，不作删除。

## 九处失败与下一步修复目标

| 新题 | 本轮失败 | 按当前合同应如何处理 |
| --- | --- | --- |
| SK03d 家庭氛围 | 用家人职业、共同务农的原话标成氛围的部分回答 | 生活来源不能作为相处氛围；保持 missing，只问相处情况 |
| LT05b 想留下的往事 | 把麻醉工作的一般服务目标当作一件具体往事 | 保留该原话，但本题仍缺本人选定的一件往事 |
| RV03 误会后的释怀 | 把经验教训标成是否释怀的部分回答 | 教训不等于释怀；仍需询问现在是否介意 |
| RV09 吃苦 | 把对努力、条件与机会的理解当作吃苦的理解 | 不借用相近概念；只问本人怎样看待吃苦 |
| RV09b 努力 | 非连续原话选择在一次修复后仍失败 | 内部引用协议失败，保留原答，不要求本人重讲 |
| RV09c 运气 | 把掌握机会的表达当作运气观点 | 依冻结金标准仍计误收；保留概念边界供后续独立复核，不改分 |
| RV06b 亏欠 | 把明确表达感谢的人登记为亏欠的人 | 感谢不推出亏欠；本项尚未回答 |
| CH03 疼爱的亲人及小事 | 漏掉已提供的接送上学片段 | 已有同题小事应收下，不再重复询问 |
| CH03b 影响深的亲人 | 从母亲疼爱本人推出母亲影响深 | 疼爱不自动证明本人认定的影响；本项尚未回答 |

这表明单问句改善了交互结构，但模型仍可能对着单一目标把相近材料硬套成答案。后续应增强通用的概念边界与引用选择约束，而不是按上述人物写补丁。本次完整失败已冻结，不修改后再覆盖同一轮分数。
