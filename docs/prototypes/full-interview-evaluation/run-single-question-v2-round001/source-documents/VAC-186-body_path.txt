問：請孫樸生老師跟我們介紹一下您原生家庭的狀況？  答：我在天津出生，出生後很少見到我父親，我的父親娶了好幾個太太，有一個裹足的鄉下大娘，一個蘇州姑娘，一個臺灣姑娘，還有我母親，來自福州的姑娘，我跟這幾個人，和家裡一群丫頭生活。當時家裡環境不錯，我從來沒有去過老家南平縣，甚至連我祖父叫什麼名字，我都記不起來了。    問：可以跟我們談一下您從軍前就學、生活的狀況嗎？  答：懂事以後，我母親已經失勢，不再受父親寵愛了。主因是天津發生一件無名女屍案，在英租界的跑馬場發現的這具女屍，後來被人誣陷為，是我父親、母親凌虐致死的丫頭，為件事，母親到東北去找我舅舅，我就跟著蘇州的媽媽、奶媽生活。經過1年多才查出來，這個案子不是我們家犯的，而是發生在曹錕的家中。一直到我6、7歲時，我的蘇州媽媽才將我送到東北。    問：到東北之後呢？  答：我轉到當時的東北，現在叫長春，日治時代叫做新京。小學一年級又轉到現在的瀋陽，那個時候稱為奉天。七七事變後，母親就帶我回來，在我的印象裡，我母親生活的環境還不錯，後來舅舅過世後。我的祖母、還有幾個表弟，全由我的母親一個挑起照顧的責任。我臺灣籍的媽媽，在經濟上也都是她在負責，後來高家三姊妹也一起跟過來，養了一大家子。    問：家族這麼複雜，您那麼小就看到這麼多的事情，會不會對您有一些影響？  答：我想有不太好的影響，對我以後的做人處世多少都會有一點影響。我也沒有什麼特別的宗教信仰，我覺得運氣還不錯，一直到目前為止，都有貴人相助。  當時在那種家庭環境中成長，我學會了反抗強權，所以後來我不管做什麼事，我對我的長官，不一定是唯命是從，除非他讓我很尊敬。相反的，我對我的部下都非常好，這個好像跟我童年的生活，多少有一點關係。    問：在這樣子的家庭狀況下，你為什麼決定從軍？  答：後來我父親都不接濟我們，母親雖然有一點錢，也禁不起養一大家子人，也許是因為心情鬱卒，母親就染上吸鴉片的習慣，這個習慣造成她經濟上相當大的開支，後來我離家之後，下定決心絕對不碰投機、典當這兩類生意。  那時讓我印象最深刻的是，我母親陸續將值錢的翡翠、鑽石，叫丫頭拿去當掉，原本價值不斐的珠寶，只典當很少的金額。另一次，從我家嫁出去的丫頭回來找母親，介紹藥品期貨，是韓國廠商經營的產品，投資利潤豐厚，我母親怦然心動，只要有積蓄就投進去，剛開始利潤很高。當我母親將大多數積蓄投入時，忽然，那個丫頭說：「那家韓國的製藥廠，被日本人給抄了」，也就是說我媽媽的錢一夕泡湯，此後，家中就開始靠典當維生。  雖然那時候家裡經濟環境轉差，母親仍然非常疼我，到讀初中的時候，我一直都是乘坐專用人力車去上學。後來經濟情況越來越差。民國34年抗戰勝利，我們的生活每下愈況，我父親那邊的情形也不理想，有一天，我剛好看到報紙上青年遠征軍二零八師招考啟事，我就偷偷的去報名考試。    問：你媽媽只生你一個？她同意你的決定嗎？  答：媽媽只有我一個兒子。但我去考試後，還有兩個表弟在我媽媽身邊。  她當然不同意我的決定，但是也沒有其他辦法，因為那時維持我上學都有問題了，她吸鴉片的嗜好又無法戒除，我就毅然從軍了。  從軍以後我的生活有了一百八十度的轉變，入伍以後，由於是知識青年從軍，部隊裡從連長、排長的幹部，對我都很好。民國35年8月15號入伍，入伍不到1年，大約是在民國36年初，軍中成立一個幹訓班，她就鼓勵我去幹訓班，我就到幹訓班受訓。受訓期間成績優異，我以前三名保送到南京，到南京中央訓練團勵志班再度集訓，畢業時我名列前三名，畢業後我掛上少尉兵階。  其他跟我同時去從軍的朋友，好多都只掛准尉兵階。我們那時候人員分發，是依據籍貫，籍貫在河北，就分發到河北大隊，籍貫在河南，就分發到河南，因為我籍貫在河北，就被分發到河北大隊。等我回去以後，回到剛入伍的部隊，去看我一些同袍，他們還在當二等兵，我已經成為少尉軍官了。但我本來在大隊部，後來派到靜海，接著整個河北大隊陸續派駐上海、寧波、廈門、石碼、長泰、岩溪，最後才移師澎湖。
