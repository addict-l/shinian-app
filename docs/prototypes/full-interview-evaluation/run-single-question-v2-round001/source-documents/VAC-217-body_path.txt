問：請侯鎮清先生先介紹一下您小時候的家庭背景。  答：我是民國16年2月20日在青島出生的。我的命運非常不好，因為我小學剛剛升四年級的時候，日本人已經打到青島來了，我從那時起就開始失學在家。我父親在青島市做生意，我跟我哥哥、母親在鄉下靠務農來維持生活。家鄉生活還說得過去。我失學後就跟著我哥哥下田。    問：可不可以請您描述一下日軍打到青島的情形？  答：我們在鄉下就聽見爆炸聲，重要的工廠都被放火燒掉了。之後，日本進來接收那個工廠，很亂。那時日本飛機也會出來轟炸！連學校他都炸。當時我們在鄉村裡面，他不敢來，因為我們有游擊隊，游擊隊打游擊戰，三個、兩個日本人，很容易被游擊隊抓去，把他武器卸下來，人就放走。要他的槍，那時候很亂啊！    問：您父母親面對這樣的時局，有沒有特別對你們有些告誡？  答：我們就是盡量避免外出，要出去的話都帶著農具，日本人看到我們帶了農具就知道你是下田的農夫，他也不過問你了。
