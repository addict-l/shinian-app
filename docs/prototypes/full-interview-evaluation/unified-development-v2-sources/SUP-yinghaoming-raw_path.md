“岁月留下了两个我，一个是长不大的应三岁，一个是三十几岁的应先生。”这是应昊茗在去年生日时写下的感言。面对镜头，他笑呵呵地感叹岁月不饶人，可头顶上的明黄色毛线帽又为他增添了几分少年气。
演员这条道路，是应昊茗曾经放弃过，而后又重新选择的。“别的事业我也不太擅长，还是想做自己喜欢的事情。”应昊茗一脸诚恳。时间也终究没有辜负热爱，无论是《古剑奇谭》中心狠手辣的“甩头哥”陵端，还是《老九门》里可爱幽默的话痨八爷齐铁嘴，抑或是《独孤天下》里隐忍痴情的千古帝王宇文邕……应昊茗塑造出一个个类型各异的角色，“大家愿意通过角色来认识我，然后更深层地关注我”，这让应昊茗倍感满足和幸福。

在《海棠经雨胭脂透》中，应昊茗饰演了自卑忧郁而又腹黑阴暗的公子哥朗月明，虽然人物设定并不那么讨喜，应昊茗却不在意，角色的转变与成长才是他更看重的。

在《超级星声》，应昊茗和我们聊了聊角色，聊了聊人生。

01

和网友同步追剧 用小号发弹幕

超级星声：《海棠经雨胭脂透》这个剧本最吸引你的是什么？

应昊茗：我觉得朗月明这个人物，他的腹黑是有原因的。他的善良单纯，他对海棠的执着，很多东西它都是有铺垫、有原因、有转化，有承上启下的东西。我觉得（剧本）比较突出人物性格，很完整。我第一次演大宅院里面的年代戏，之前都很少演过。

超级星声：所以当时为了这个角色，做了哪些准备？

应昊茗：因为没有历史可查，所以只能通过剧本、通过人性，尽量把角色圆满。如果说有历史可查，或者说有真实人物存在的话，去查他的历史、背景、人物故事能更好地帮助你来分析角色。《海棠经雨胭脂透》是在一个（特定）环境下，但是更多讲的是宅院里面的爱恨情仇，包括家族历史、世代世交、怎么经商去让自己的家族发扬光大，以小家来体现大家，但是跟当时的社会我觉得还是没有太多挂钩。

![Image 2](http://image.thepaper.cn/www/image/42/574/300.jpg)

▲《海棠经雨胭脂透》应昊茗定档海报/应昊茗微博
超级星声：你自己有没有在同步追剧？会同步去看网友们的一些弹幕吗？

应昊茗：有啊，有追。我有时候也会跟网友聊这个弹幕。我自己也会发，问为什么之类的。

超级星声：怎样分辨哪条弹幕是你发的？

应昊茗：那分辨不出来，我用的是小号！

超级星声：在《海棠》的弹幕里，有没有看到还有观众在喊你“阿邕”。看完以后心里面会觉得还挺开心的嘛？

应昊茗：有有有，叫阿邕，叫八爷，都会有。（看到以后）会挺开心，因为大家愿意通过一个角色来认识你，然后更深层地关注你。我觉得这并不是我有多好，可能是角色带给大家的吸引力吧。

超级星声：如果看到一些吐槽的弹幕你会怎么办？会跟他在线“吵架”嘛？

应昊茗：吵什么，我就虚心接受，萝卜青菜各有所爱。如果说全世界都觉得你很好的话，反而是不好的。

02

回归纯粹的演员道路 心中有个军人梦

超级星声：角色会反过来给你带来什么变化吗？

应昊茗：不同的（角色）人生会带来不同感觉。像古装戏，如果不做演员的话，你一辈子都去不到这样一个时空,去享受那个时代体验一把做皇帝的瘾；说到民国时期，你可能平常也不会自己穿唐装，或者说（穿）大褂立领走在大街上；但是现代戏的话就会好很多，大家都可以接触到。所以这就是每个角色带给我的不同感受，也是我最盼望的初心。

超级星声：现在挑选剧本的标准大概是什么？

应昊茗：尽量让自己多演点正能量（的角色），演点好人吧，不想再演坏人。但是如果说有好的角色，好的团队，我还是愿意尝试的。

超级星声：有没有具体一点的想要尝试和挑战的角色类型？

应昊茗：军人，够好吧？“人民解放军为人民”，每个男孩子好像都会有这样一个梦想。

![Image 3](http://image.thepaper.cn/www/image/42/574/301.jpg)

▲应昊茗在阅读笔记满满的剧本/应昊茗微博
超级星声：现在很多演员开始公开地表达“求职难”这件事情，你会有这样的压力吗？

应昊茗：是，可能大家都说是行业的寒冬，我觉得这反而是让大家积攒能量的时候，这才是真正比拼实力的时候。我觉得不急不躁，让自己平常心对待、放平心态努力去做就好了。

超级星声：所以从走上演员这条路一直到现在，有过想要放弃的时刻嘛？

应昊茗：有，我以前有想过放弃，也放弃过三五年吧，但是回头来还是继续干自己喜欢的事业。因为你总会觉得干别的事业不是你所擅长的，你会觉得可能不纯粹。

03

低谷不代表郁闷 “没心眼”是一种心态

超级星声：你的微博上有练习拳击的照片，也有过踢足球的照片，但是与此同时还会进行禅修。在运动和安静下来的时候，你一般都在想些什么？

应昊茗：没有，运动很纯粹，我运动时候不会想任何东西。如果不专注的话，我觉得你干任何一件事情都干不好。包括演戏的时候，如果你在想晚上吃什么，明天该怎么过，那没法（演好）。

静下来的时候，你可以什么都不想，也可以想很多很多事情。比如突然会想起别人点拨你的一句话；或者想想以前自己做错过的事儿，以后是不是还要在哪些地方注意；还有以后的路该怎么走，面对什么样的人、面对什么样的事，从中你可以得到一些感悟。这样想的话会帮助你去理解角色，然后更好地去面对你身边的人，你爱的人、你的朋友、你的家人。

![Image 4](http://image.thepaper.cn/www/image/42/574/302.jpg)

▲在生日当天，应昊茗选择和妈妈一起去普陀山清修祈福/应昊茗微博
超级星声：在遭遇低谷的时候，你会怎样缓解自己的情绪？

应昊茗：以前我会选择发泄，但我现在越来越觉得需要让自己安静。低谷不代表郁闷，有时候也会看一些讲座，或者说看一些书。就是说人真正走到低谷的（时候），你无论上到哪一点都是进步，爬升一点点就是进步。因为你到低谷不能再低了，你也知道自己最差到什么样了，我觉得是件好事。

超级星声：去年生日的时候在微博写道“岁月成就了两个你，一个是长不大的应三岁，一个是三十几岁的应先生”，现在你觉得这种自我评估有没有发生变化？

应昊茗：岁月不饶人，哈哈哈。虽然说我的真实年龄已经三十几岁了，但是我觉得我的心态还像个三岁的孩子。很多人都说，说句好听点我像小孩，不好听的话就是你好蠢好二啊。

超级星声：蠢和二体现在哪里？

应昊茗：没心眼。尤其是对朋友、对家人、或者对身边的人都属于这样。我比较直，有什么说什么。可能伤害到你了，你不要在意；你伤害到我，我也会说没事儿啊。这不能算优点，也不能算缺点，我觉得是一种心态。

![Image 5](http://image.thepaper.cn/www/image/42/574/303.jpg)

▲应昊茗生活照/应昊茗绿洲
超级星声：假如遇到喜欢的人，你觉得最能表达爱意的方式是什么？

应昊茗：真诚、温柔以待、理解、包容。在我能力范围之内，我一定会让我女朋友开心的嘛。

超级星声：你觉得喜欢和爱有什么区别？

应昊茗：喜欢跟爱，其实不是一个程度的吧。喜欢，有可能就是一面之缘。你可以喜欢很多东西，也可以喜欢很多人，没有性别歧视，其实也没有贵贱之分。但至于爱，有句话说的好嘛，“心比长相好，懂比爱重要”。怎么去理解这个爱，其实每个人都不太一样，有的人觉得静静地陪着我就是爱，有的人觉得轰轰烈烈才叫爱。我觉得喜欢是对人产生一种好感的初级阶段，是一个升华的地基。
