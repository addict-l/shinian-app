Title: 讲述｜金晓贵：到祖国最需要的地方去

URL Source: https://www.gzu.edu.cn/_t2805/2026/0509/c17516a272833/page.htm

Markdown Content:
编者按：2011年5月9日，时任中共中央政治局常委、中央书记处书记、国家副主席习近平同志来到贵州大学中国文化书院，与青年学生围坐交谈，深情寄语“奋发有为、自强不息，做中华民族的脊梁”。这一幕，已镌刻在贵州大学的校史里，更镌刻在在场每一位同学的人生年轮中。十五年白驹过隙，当年的在场学生如今或扎根西部，或放眼全国；或执鞭育人，或投身国防；或勤政为公，或商海弄潮，各自把“做中华民族的脊梁”嘱托写在了祖国大地上。本系列报道采访了当时在场的学生，共忆那一温暖瞬间，共述十五载成长答卷。

![Image 1](http://thirdparty-lib.oss-cn-hangzhou.aliyuncs.com/mrp-media-news-pusher/ab48c6c2-0d33-473e-bb8f-f4f99da7eaf0/articles/1f2c67d1-ec24-4c85-b411-d985ce25451c/20260509222314-7YzPrQ-20260506191822-dvzB4U-.jpg?x-oss-process=image/resize,w_800)

讲述人：金晓贵，贵州大学2009级汉语言文学专业本科生（人文学院少数民族实验班）。2013年毕业后回到黔东南，历任丹寨县排调镇信贷员、马鞍村驻村第一书记、丹寨农商银行支行行长、总行纪检监察室主任、团委书记。2025年通过遴选调入贵州省纪委省监委，现派驻贵州广电网络传媒集团纪检监察组。曾获《人民日报》2017年扶贫报道典型人物，贵州省金融扶贫创新产品“青扶贷”主要推动者之一。

采访人：当时您在现场听到的哪一句话对您触动最大？

金晓贵：我是从农村出来的学生，当时记得最清楚的一句话就是“到基层去，到农村去也是在做贡献。希望大学生们积极到基层去，到国家最需要的地方去成长成才，报效祖国。在报效祖国、服务人民的过程中，实现自己的人生价值”，在习近平总书记的激励下，当时就暗暗下了一个决心：毕业之后，我要深入基层去，到祖国最需要的地方去。

采访人：当天，有没有哪个细节让您到现在还记得特别清楚？

金晓贵：当天下午道路两旁挤满了贵州大学的师生，大家非常激动，好多同学争相和习近平总书记握手。习近平总书记非常亲切和大家握手。然后大家纷纷挥手，好多同学都感动得热泪盈眶。

采访人：您在排调镇当信贷员的那几年，有没有一些特殊的故事？

金晓贵：我记得2014年初的时候，我们在下乡的过程当中，走到一个比较陡峭的路段，因为当时这个路段没有硬化，都是一些石头和泥巴比较多的路，途中我们的车爆胎了，又正好碰到了下大雨，大雨滂沱、电闪雷鸣，又在山里面，前不着村后不着店，叫救援也不太现实。

我们在车里面等到下午大概五六点钟的样子，雨稍微小一点就出来准备修车。有一个老百姓路过，他从背上的筐里面拿出了刚摘的黄瓜，给我们每人送了两个。当时感觉那是我这一辈子吃过最好吃的黄瓜。也感觉当地的老百姓的淳朴、善良和热情。当时我被内心深深的触动，回想起习近平总书记激励我们的那些话，就感觉到基层来工作是非常值得的。

采访人：您2016年3月刚到马鞍村时，遇到的最大困难是什么？据说村民当时觉得您是“书呆子”，吃了很多闭门羹，有没有哪一个具体的闭门羹让您印象最深？

金晓贵：我记得最清楚的是一位家族族长的老人家，刚开始对我们驻村干部心存质疑，有点爱答不理，但是后来因为帮他解决了他家的土地纠纷问题，他就切实改变了对我们的看法和态度，还主动邀请我到他家。他说：“以前不理你们，是因为我觉得你们就是做些表面工作。现在看来，你是实实在在的。你是第一个跑到学校去关心留守儿童的干部，也是第一个跑到病房去看望生病困难群众的干部。所以我现在认可你，以后我们这个村寨有什么问题，你尽管找我就行了。”从这以后，我们的驻村工作顺利开展起来了。这件事让我深刻地认识到：只要你把人民放在心上，人民就会把你高高举起。

采访人：如果让您结合自己从基层信贷员一路走来的经历，对现在贵大的学生说一句话，您最想说什么？

金晓贵：我最想说的是希望师弟师妹们继续发扬贵州大学“明德至善、博学笃行”的校训精神，吃苦耐劳，到基层去磨炼去成长，在无私奉献中实现自己的人生价值。

采访人：从2009年入学到现在，您的人生几乎都是和贵大、和黔东南的土地紧紧连在一起的。如果用一句话总结这十五年，您会怎么说？

金晓贵：十五年来我始终牢记习近平总书记“在报效祖国、服务人民的过程中，实现自己的人生价值”的殷勤嘱托，让我坚定了人生道路的选择，找到了全心全意为人民服务的意义和价值。
