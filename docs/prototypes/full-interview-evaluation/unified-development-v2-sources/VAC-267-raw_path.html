父兼母職兩頭忙 子女孝順成就高

口述人：李昌明
﻿問：您教導小孩時有沒有對他們有什麼特別的要求呢？尤其您又是父兼母職將小孩養大的。 答：我太太過世的時候，我小女兒李幼嵐，還沒國中畢業；老大是高中畢業，老二國中還沒畢業。老大在我太太過世以後，她說爸爸你很辛苦，你努力工作養三個小孩，你一個人要當爸爸也要當媽媽，還要上班，還要給弟弟妹妹送便當，樣樣都要做，回來洗衣服擦地，我們還沒回來，你哪樣不做，我不要讀書了。 我講讀書妳花不了我多少錢，公家拿錢嘛，津貼一點零用錢後，我再出一點就夠了嘛，我說妳現在不讀了以後妳怎麼辦？妳不能商職畢業就不讀了，要考大學嘛；她說等爸爸輕鬆一點，等弟弟妹妹大一點，我再來讀可不可以？我講妳這個
