### 做法（代码 0 token 部分）

- **按故事归并（`story.py`、`plan-v5.txt`，`book.py --stories`）**：规划一次调用（开思考）把全书原话按句（〔1〕〔2〕编号）归成故事，每个故事只排进一章一节（或章末回望），别的章用一句标出的“呼应”带过；写作 `write-v7.txt` 拿到一个故事在各题里的全部讲法，合起来写一遍。代码兜底：规划漏归的句子归回同一单元相邻句的故事；整题漏归的并入内容二元组最接近的故事（不再出现“本人认定的中年收获”这类题库标签节名）；整题归进别章故事、但并不重讲那个故事的晚年/家庭/回望感悟句（内容覆盖 < 0.35）退回本模块章末；每个模块的章都保留。
- **事实层补漏 `fill-v1.txt`**：代码找出本章故事里带“只在 ≤2 个回答出现的具体词”却没写进去的原话句，交模型补成事实句（已有句子一字不改）。
- **扩写收紧**：`expand-v2→v4.txt` + `check-v6.txt`（新增“替人编”类型，并让核对列出每个加写句的具体名词）+ 代码守卫（`story.guard`）：加写句里的物件/地点/人物词必须在本书原话出现（词表 + 核对列出的名词 + 单字物件“纸笔门窗灯…”）；他人作主语的动作/作息/心理/身子；套话家族全书只用一次；开头两字章内不重、三字全书 ≤2；加写不带数量时长（“几亩”“好多年”）和“记不清/记不真了”。
