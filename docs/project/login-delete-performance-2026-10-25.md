# 两端登录与删除性能修复及同步核查

2026-10-25，用户已审核通过本轮版本并授权提交、推送。范围为 Android 与 iOS 的登录后加载、删除人物、删除回忆耗时，沿用现有业务规则和布局。本次不更新生产后端。

## 行为变化

- Android 首页共用一轮人物、回忆结果，身份校验只请求一次；登录与业务请求复用连接池，认证仍逐请求绑定当前会话。
- iOS 人物与回忆共用进行中的读取，无 TTL 数据缓存；显式刷新重新读取服务端，列表不等待所有封面，图片按可见视图读取。
- 两端删除只在服务端确认成功后更新列表、人物关联和统计，保留必要的本机历史清理，不再追加整页刷新。旧查询不能恢复已删除内容。
- 人物删除后保留历史正文和共同回忆；身份隔离、版本冲突、网络失败、重复请求及清理失败重试规则保留。

服务端隔离测量：登录 0.503–0.539 s，其中 SQL 0.005–0.009 s；带历史和媒体元数据的删除约 0.076–0.097 s，其中 SQL 约 0.049 s。测试 SSH 隧道有明显长尾，不能把其数秒耗时归因为数据库或真实手机网络，也不据此宣称所有网络都已很快。

正常 iOS 产品包已覆盖安装并恢复原登录与关怀模式，本机既有文件保留。Android 模拟器的首次 Gradle UI 测试清理卸载了目标 App，无法确认或恢复此前未知登录状态；已重装最终正常包并停留空登录页，后续验证改用独立包。真实手机及原家庭云端数据未受影响。键盘、输入法和按键捕获设置未修改。
