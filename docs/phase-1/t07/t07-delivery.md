# 老师运行与交付指南

老师只需 Mac、Xcode、iPhone 模拟器和家庭登录信息。前端使用现有阿里云服务，GitHub 后端用于检查实现或由维护者另外部署。

## 1. 获取最新工程

访问仓库，选择 `main` 分支，使用 Code → Download ZIP 后解压；或者运行：

```sh
git clone --branch main https://github.com/addict-l/shinian-app.git
cd shinian-app
open frontend/AIMemoirs.xcodeproj
```

以后使用 `git pull --ff-only origin main` 获取更新，再运行 `git log -1 --oneline` 核对版本。ZIP 要重新下载，旧 ZIP 不会更新。仓库公开，无需获取项目维护者的 GitHub 登录信息。

## 2. 启动和登录

交付验证使用 Xcode 26.6、iPhone 17 Pro / iOS 26.5；最低部署目标为 iOS 18.1。工程采用 Xcode 文件系统同步目录，建议使用 Xcode 26。

在顶部选择 `AIMemoirs` Scheme 和 iPhone 模拟器，按 Command + R。产品工程仅包含 App，没有测试目录或外部包依赖。默认开发团队为空，模拟器构建不需要 Apple 开发者账号。

登录账号 `family`；密码由维护者通过单独渠道提供。默认连接 `https://aimemory.47-82-83-74.nip.io`。登录后是现有家庭，显示当前人物和回忆；老师的新增与修改也保存到该家庭。

`AIMemoirs-DesignPreview` 仅用于离线设计样例；需要体验云端功能时使用 `AIMemoirs`。

## 3. 建议试用流程

1. “新的回忆”选择已有家人，直接查看该人物聊天。创建新人物时填写姓名、家庭身份，创建完成后准备开场白。
2. 输入一段明确的故事，可以附照片。发送后用户文字立即出现，模型回复随后追加。整理入口在合适停顿提示一次；继续补充后若想整理，可说“帮我整理这段回忆”。
3. 点击“整理成一段回忆”，查看第一人称草稿。通过编辑修改标题和正文，校对后确认保存；口头要求保存不会跳过草稿确认。
4. 在已保存回忆中查看、编辑信息和照片。删除前有确认，确认后删除所属讲述，人物开场白保留。
5. “家庭胶片 → 人物头像 → 制作／继续制作回忆录”，至少需要该人物一段已保存回忆。
6. 封面选择文字、单照片或拼贴，照片入口在样式选项下方。取景通过“调整照片取景”进入单独窗口，主页面滑动用于滚动。
7. 下一步整理故事顺序、照片顺序和 14／16 pt 字号，再生成整本预览。A5 目录可跳转，正文连续编号；短文与首图同页，其余照片完整分页。
8. 点击分享，核对最新内容后在系统分享面板选择“存储到文件”或其他目标。内容有变化时先重新生成并查看预览。

模拟器相册没有图片时，可将本机图片拖入模拟器导入后再选择。中文输入可以直接输入或粘贴，原生语音实际识别效果留到真机体验。

## 4. 故障排查

| 表现 | 处理 |
| --- | --- |
| 没有可用 iPhone 模拟器 | Xcode Settings 的 Components／Platforms 安装 iOS Simulator Runtime，选择 iPhone 设备 |
| Team／签名／profile 报错 | 先确认运行目标是模拟器；真机需要选择自己的开发团队 |
| 显示离线设计人物 | 检查 Scheme，改为 AIMemoirs，并清除自行添加的设计预览启动环境变量 |
| 登录失败 | 核对单独提供的当前密码；在“我的 → 设置”退出后重新登录 |
| 网络无法连接 | 浏览器打开默认地址的 /health，输入家庭账号；维护者检查服务器与证书 |
| 未认证 /health 返回 401 | 正常；家庭认证通过后应返回 status=ok、database=ok |
| 模型回复失败 | 原文保留，点击重试；维护者检查大模型配置及服务状态 |
| 整理按钮尚未出现 | 继续讲清主要人物与事情，或明确提出整理请求；信息存在关键冲突时先澄清 |
| PDF 分享要求重新预览 | 故事或制作设置已更新，重新生成并查看后再分享 |
| 没有封面照片选项 | 选择单照片／拼贴，使用预览上方的“选择／更换封面照片” |

## 5. 真机运行（可选，尚不作为本次已通过验收）

连接自己的 iPhone，在 Xcode Settings 添加自己的 Apple 账号，在 App target 的 Signing & Capabilities 选择自己的 Team；需要时改成该团队可用的唯一 Bundle ID。当前真机 SDK 调试标识与模拟器不同，另一台 Mac 应自行配置。手机需信任电脑，开启开发者模式并信任开发证书。

真机中文语音、实际第二台设备和老师自己的 Mac 由相应人员实际操作验收。本次的模拟器／隔离自动化检查不会冒充这些体验。
