# 关怀版 1.0.5 状态栏同步核对

用户要求核对已批准的 `c9afce6` 状态栏、摄像头安全区和普通版六板块布局是否保留在关怀版交付中。

结论：已保留在当前源码和 1.0.5 APK。此次没有修改生产源码、版本号或交付 APK，只新增窗口验证用例及本记录。

## 源码与安装包

- `ImmersiveWindow.kt`、`JournalTheme.kt` 与 `c9afce6` 字节一致；主窗口仍显示透明状态栏，并使用状态栏与摄像头切口的最大安全边距。
- `MainActivity` 仍应用窗口策略与 `shinianContentInsets()`。
- 普通模式的 `LifeModuleSelection` 及板块列表与该提交一致，保留两列三行及进入按钮的一屏布局。
- 1.0.5 APK 的 SHA-256 为 `11b7550a128e77f042919e43c8be6c3860e62d80461a7232a7d7107efe6505be`，安装包与原交付文件一致。

## 实际窗口验证

复用现有 Android 模拟器、竖屏、普通字号，不改键盘或系统输入设置。以下 6 项全部通过：

1. 真实关怀页面显示状态栏，状态栏和切口安全边距只消费一次，返回按钮另加自身 6dp 顶距。
2. 关怀背景与状态栏区域相邻像素连续；25%、50%、75%、90% 横向采样的最大 RGB 通道差为 1，验收上限为 2。
3. 普通版 360×640 竖屏六个板块及进入按钮完整显示。
4. 普通版 400×880 竖屏六个板块及进入按钮完整显示。
5. 普通版标题与返回按钮避开真实状态栏和摄像头安全区。
6. 普通暖色页面与状态栏区域无明显颜色接缝。

实际设备状态栏和切口的顶部安全高度均为 142px，内容从 142px 开始；关怀返回按钮从 158px 开始，符合安全区仅应用一次的要求。原生截图包含系统时间、电量图标。

## 对静态判断的修正

初次仅按代码发现 `CareBackdrop` 没有复用普通背景的 48dp 淡入，曾怀疑顶部过渡遗漏。实测显示，关怀背景的渐变绘制会延伸进入状态栏区域，上下边界已连续。要求是自然衔接，状态栏区域不必为纯纸色，因此移除了测试中额外的“必须纯纸色”假设，保留真实窗口、安全区和 RGB 连续性断言。无需增加背景补丁。

此前 402×778 页面比较有意裁去系统安全区，不能单独证明状态栏表现；本次新增了未裁系统区域的实际窗口截图。
