# Android 照片界面对照记录

日期：2026-10-21（Asia/Shanghai）。用户要求上传图片界面与当前 iOS 一致，本项作为 Android 整体审核的补充，尚未 commit 或 push。随后按用户提供的微信截图替换了选图入口，详见 [微信式选图补充](wechat-picker-verification.md)；以下 iOS 对齐继续适用于应用内待发送照片、消息和大图。

## 调整内容

对照 `ios/AIMemoirs/Features/NewMemory/Chat/` 中的 `JournalChatView.swift`、`JournalSelectedPhoto.swift`、`JournalUserMessage.swift` 和 `JournalMessagePhoto.swift`：

| 状态 | Android 调整结果 |
| --- | --- |
| 选中照片 | 72dp 方形缩略图、10dp 圆角，84dp 容器、8dp 间距，放入白色输入框容器；移除按钮视觉直径 24dp，Android 点击范围 48dp。 |
| 输入与读取 | 有照片时提示“也可以写几句话…”，读取显示进度圈；正常选中和已上传照片不额外显示状态文字。失败保留“上传失败”。 |
| 发送中 | 输入框预选条隐藏，保留照片状态与稳定 ID；消息区显示全部待发送照片，最多九张。 |
| 发送后 | 照片独立在文字气泡上方。单张 4:3，双张 129:96，三张以上最多三列正方形；最大宽度 264dp、间距 6dp、圆角 14dp，末行不拉宽。只有文字使用桃色气泡。 |
| 载入与错误 | 远端显示加载圈；失败整格可点重试，大字号错误文字可滚动。本地图像解码失败显示照片图标，避免空白框。 |
| 查看大图 | 纸色弹出页，标题“讲述照片”、按钮“关闭”，完整比例显示图片，显示区最高 400dp；标题操作避开系统状态栏。 |
| 横屏与大字号 | 预选条使用“管理已选照片（N/9）”入口，管理页标题“已选照片”、按钮“完成”。关怀模式保留对应管理入口。 |

当前默认使用微信式四列有序照片选择器，权限与备用系统选图由 Android 提供。应用内上传预览及消息仍按 iOS 对齐，不分发 Apple 字体。
