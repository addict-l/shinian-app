# Android 关怀模式对齐 iOS · 1.0.5 审核记录

状态：用户于 2026-10-25 明确审核通过 Android 1.0.5，并授权正式提交及推送主分支。本记录随已审核的安卓改动提交；实际提交标识以 Git 日志为准。

本轮以当前工作区的 iOS 实际运行界面为参考，重新校准 Android 关怀模式。沿用竖屏、普通系统字号的验收范围。APK 从完整现有工作区构建，包含原有前端修改，没有从 Git HEAD 另建缺少本机修改的交付副本。

## 迁移内容

- 首页、回忆列表、家人选择和添加、更多：对齐标题与计数、人物筛选、封面比例、按钮、间距、圆角与阴影。
- 讲述、人生概览问答、经历核对、选题及历史：使用相同的页面结构、问题卡、分段进度和底部操作区；核对页两个次级按钮等宽等高。
- 保存前预览、草稿编辑、保存成功、阅读和回忆编辑：对齐正文行距、照片、信息卡、工具栏及分组表单。保存成功页使用实际家人回忆数量。
- 家庭胶卷、人物详情、设置和隐私：沿用当前 iOS 的紧凑布局；胶卷保持人物行的加号入口。
- 长文字与照片在有限高度下内部滚动，保留发送、重试及次级操作。无界的外层滚动布局不再叠加内部滚动容器。

关怀入口按模式分支接入；普通模式、已有的保存/取消/冲突确认、照片上传和服务端采访状态机沿用原实现。iOS 源码与 Android 数据层相对本轮起点的文件哈希一致。工作区原有后端改动保留，本轮没有部署云端服务。

## 对照口径与保留差异

20 组对照使用同一批人物、文字和照片。iOS 原图为 1206×2622，按 @3× 移除顶部 62pt、底部 34pt 安全区后，内容为 **402×778pt**；Android 在相同逻辑尺寸采集。审核页支持并排、透明叠加和打开原图。

系统字体和原生控件仍由各平台渲染。正文沿用项目相同的 Noto Serif SC 字体；系统符号的自然布局尺寸用实测数据校准，图形使用项目自有矢量。审核图展示实际字形差异，不将像素差异隐藏或宣称整页完全相同。

草稿编辑在 iOS 使用原生 sheet，顶部余量与圆角来自系统窗体；Android 使用全屏编辑页。当前 iOS 回忆子列表还会同时显示系统返回栏与关怀工具栏；Android 保留一个返回入口。两项差异已在对应审核页标注。
