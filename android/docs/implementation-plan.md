# Android 完整移植与统一审核

日期：2026-10-21（Asia/Shanghai）。

用户确认：用 Android Studio 将拾年当前本地 iOS 版本完整复现在 Android。随后明确要求“不用分六块，直接一次性做完我来审核”，因此本次按一个整体交付、整体审核，审核前不创建 commit 或推送。

## 业务与视觉基准

- 主线为 `ios/` 当前源码及运行结果，包含已有未提交改动；不回退到旧 `ios/legacy/`，不清理或混入原有修改。
- 保留暖纸、杏色、文字层级、原图标、四个普通导航入口，以及关怀模式独立大字页面和三个导航入口。
- 注册登录、人物、持续聊天、人生骨架、六模块、回忆草稿与管理、家庭胶片、回忆录和关怀模式均在本次范围。
- 使用同一 HTTPS 后端与家庭账号；后端不因 Android 移植另行发布。采访主问与状态以服务器实际返回为准。
- 状态栏、系统键盘、权限、相册、语音服务、文件保存和分享使用 Android 原生机制。
- 不分发 Apple 系统字体。标题和故事字体沿用原 OFL Noto Serif SC，正文使用 Android 中文系统字形。

## 整体实现

同一 Android Studio 工程内并行实现数据契约、浏览页面、采访聊天和回忆录，再统一整合。稳定请求标识、版本冲突、账户隔离、未发送文字和照片、待同步回忆录设置属于验收内容。

拟用整体提交标题：`feat(android): reproduce Shinian app with native Compose client`。只有用户明确通过本次整体人工审核后才创建正式提交并推送实际主分支。

## 验收范围

1. Gradle 构建、JVM 业务测试、Android Lint 和模拟器仪器测试。
2. 独立测试家庭的注册、多设备会话、人物、采访、照片、草稿保存、回忆编辑及回忆录设置联调。
3. 页面截图对照；小屏、横屏、大字体、键盘与关怀模式操作检查。
4. A5 PDF 中文正文尾部不遗漏、照片可见、目录链接正确、预览和文件分享可用。
5. Android Studio 正确打开工程，交付 APK、工程和可复核验收记录。

本次没有 iOS 源码与云端代码改动，因此不执行后端发布。现有 iPhone 17 Pro 只用于对照当前 iOS 外观。语音识别的真实麦克风效果需要具有可用普通话识别服务的 Android 设备，模拟器结果单独记录。

## 照片界面对齐补充

用户在整体审核期间追加“上传图片的界面也和 iOS 端保持一致”。沿用同一次整体审核，不拆分提交。对照当前 `JournalChatView`、`JournalSelectedPhoto`、`JournalUserMessage` 与 `JournalMessagePhoto`，调整选中缩略图、输入框、上传中消息、发送后网格及照片查看页。保留现有照片上传、草稿恢复与请求标识契约，继续使用 Android 系统选图器。验证与截图见 [照片界面记录](photo-ui-verification.md)。

用户随后提供微信选图截图，要求将选择照片界面改成同样的交互。以新参考替换应用内默认选图入口：深色全屏、四列方形网格、右下角有序勾选、相册切换、全屏预览、底部预览/数量/完成按钮。确认后回到讲述输入框，最多补足九张，沿用照片压缩与上传流程。图库授权支持全部/部分/拒绝，权限不足或空图库提供系统选图入口。原图上传不在本项内，既有服务会规范化照片，界面不放无效的“原图”控件。仍按用户指定在实现、验证后一次整体审核。
