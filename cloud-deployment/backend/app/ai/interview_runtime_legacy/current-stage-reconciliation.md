# C30 本地阶段约束复核

最初假设要求被选内容的每个分句都属于现在，并要求混合原问中的短答重复提供时间。保存了初始实现、合成题及红绿日志于 development-history 和候选目录；未修改真实人物 gold、历史失败或分数。

离线回放发现两处退化：过去与现在的对照被误挡；实际原问已问现在爱好时，简短爱好回答因原问另含旅游计划而被误挡。这两项假设违背业务基准的充分性与原问补足省略规则，故修订合成测试而非放宽真实评分。

当前限定：原问的现在子问可补足省略；本人明说的未来计划在原回答上下文中仍排除，不能通过只引末句隐藏未来前提；现在态度可携带过去对照。混合了现在活动和未来计划的值暂不整体收为现在，交给通用 B 核对通过原话拆分，代码不自动创造摘要。阶段拒收与未绑定状态必须送达 B，不能只依赖模型自己发现。

此为本地规则修订与离线回放，不是新的 DS 通过率，不能替代三轮验收。
