# v1.26 通用修订

由第004轮完整失败引出两项通用缺陷：现在活动与未来旅游计划混选；概括的定义关系被整个塞入概括字段，解释字段反而只取重复。原始失败、评分、gold、全部抽样保持不变。

修复包括：把代码的时段未绑定状态送达 B；只选择目标阶段的自足原话，保留真实原问以理解省略；概括父项与定义子项分别引用。当前阶段约束按原回答的局部条件排除未来计划，允许充分的现在回答携带过去对照。早期过严合成假设与回放退化保留在 development-history 和 current-stage-reconciliation.md。

本地验证：181核心检查、895全合同边界通过；13阶段边界、2反馈检查通过；63语义/人工脚本/反馈测试通过。离线重放第003轮20检查点无变化，第004轮25检查点仅未来节奏误收变为待澄清，另外两个曾被误挡的充分回答已恢复。以上不是实际DS通过率。
